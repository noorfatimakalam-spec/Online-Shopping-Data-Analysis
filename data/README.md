# Data

The raw dataset is intentionally not included in this repository because it is approximately 22.6 MB and can be retrieved directly from the UCI Machine Learning Repository.

The analysis script downloads UCI dataset ID 352 through the `ucimlrepo` package.

Source: https://archive.ics.uci.edu/dataset/352/online+retail  
Citation: Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33
